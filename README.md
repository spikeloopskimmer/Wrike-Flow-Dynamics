## Features

- Advanced project templates (Gantt, Kanban, Board, Table) optimized for rapid sprint planning, resource allocation, and professional workflow management.
- Workflow automation rules (Wrike Automations) to streamline repetitive status updates, approval routing, and deadline notification tasks.
- Custom dashboard widget presets and report configurations for enhanced visibility, cross-folder data rollups, and consistent executive reporting.
- Quick-switch macros and custom keyboard shortcut profiles for seamless navigation between different views, dashboards, and the proofing module.
- Pre-configured Resource Management and Time Tracking templates with automated workload balancing, capacity planning, and budget monitoring routines.
- Comprehensive documentation and step-by-step setup guides for all included tools, CSV/JSON template imports, and modules.
- Integration examples and bridge scripts for third-party productivity ecosystems (e.g., Slack, Microsoft Teams, Salesforce, Tableau, GitHub).
- System resource optimization configs for faster large-project rendering, reduced browser memory footprint, and optimized conditional formatting logic.
- Ready-to-use intake forms and request tracking routines with automated data validation, assignment routing, and SLA monitoring setups.

## Requirements

- Windows 10/11 (or macOS / Linux)
- Modern web browser (Chrome, Edge, Safari, Firefox) or installed Wrike Desktop App
- Active Wrike account (Business or Enterprise edition recommended for advanced automation and Resource Management features)

## Usage

To utilize the included resources, download the package using the link above and extract the contents to a local directory. Run the provided setup utility (`Setup.exe` or `Install.ps1`) to integrate the custom project templates, automation rule definitions, and dashboard configurations directly into your Wrike workspace via the native import tools or REST API. Follow the on-screen prompts to complete the configuration process. For detailed customization and advanced API automation usage, refer to the `GUIDE.md` file included in the archive.
